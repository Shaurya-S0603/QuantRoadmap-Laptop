SYSTEM study website

Open https://quantroadmap-system.streamlit.app/ in your browser.
The hosted site includes all roadmap, NTU course, study-resource, project and
computing-strategy pages. No phone pairing or local script is needed.

Optional local development: install Python 3.11+, then double-click
Start_SYSTEM.cmd or run:
  python -m pip install -r requirements.txt
  python run_laptop.py

The website is read-only and independent of the Android app. It does not import
backups, receive phone data or record completions.
